# 📘 English Verb Dictionary & Quiz 🚀

A 2-in-1 web application designed to master English verbs. It combines an **advanced verb search engine** (regular and irregular) with an **interactive Quiz system** to test your knowledge.

## ✨ Main Features

### 🔍 Verb Finder
* **Complete Database:** Regular and irregular verbs with their conjugation (Past & Participle).
* **Smart Search:** Filter by Spanish meaning or English spelling.
* **Quick Filters:** Instantly categorize between regular and irregular verbs.
* **Premium Design:** Elegant interface based on *Playfair Display* and *DM Sans* typography.

### 🎮 Verb Quiz (Game Mode)
* **Multiple Modes:** Practice meanings, past tense, or participles.
* **Visual Feedback:** Animations for correct and incorrect answers.
* **Live Stats:** Score tracker, Streak, and personal best.
* **Results:** Final summary with a star-based rating system.

## 🛠️ Built With
* **HTML5:** Semantic structure.
* **CSS3:** Native variables, Flexbox/Grid, and custom animations.
* **JavaScript (Vanilla):** Filtering logic, game engine, and state management.
* **Google Fonts:** Integration of Syne, Space Mono, and DM Sans.
